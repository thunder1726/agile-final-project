# Agile Final Project — Digital Banking Application

A practical Scrum/Kanban project for a retail digital banking application.

## Product goal
Provide customers with a secure, simple way to manage accounts, transfer money, pay bills, manage cards, receive alerts, and access statements.

## Workflow
Product Backlog → Sprint Backlog → In Progress → Review/QA → Done

## Product backlog
1. View account balance
2. View recent transactions
3. Manage beneficiaries
4. Transfer money between accounts
5. Pay a bill
6. Manage debit-card controls
7. Configure transaction alerts
8. Download account statements
9. Refactor authentication/session handling (Technical Debt)
10. Improve API monitoring and error handling (Technical Debt)

## Course project notes
Requirements 9 and 10 are intentionally treated as Technical Debt for the course exercise.
